## P1 — Colonne "Devis lié" dans RdvTab

### Objectif
Afficher directement dans le tableau RDV tous les devis associés au client, identifiés par son email.

### Données
- `AdminDashboard.vue` passe un nouveau prop `quotes` à `RdvTab` (même pattern que `profiles` déjà passé).
- `RdvTab` calcule un `computed` `quotesByEmail` : `quotes.filter(q => !q.archived)` groupés par `client_email`, triés `created_at` desc.
- Jointure : `appointment.invitee_email === quote.client_email`.

### Affichage
- Nouvelle colonne `<th>Devis</th>` insérée après la colonne Email, avant Objet.
- Pour chaque devis : `<button class="arch-status arch-status--{status}">#{quote_number}</button>`.
- Classes `arch-status--*` **déjà présentes** dans `admin-dashboard.css` — aucun CSS ajouté.
- Plusieurs badges empilés en `flex-col gap: 3px` dans une `<div class="devis-list">`.
- Aucun devis → `<span class="devis-none">—</span>` (color `#a0aec0`).

### Interaction
- Clic sur un badge → `$emit('go-to-quotes', clientByEmail[email])` si le client a un compte dans `profiles`.
- Si l'email ne correspond à aucun profil → badge non cliquable (`cursor: default`, pas de hover).
- `go-to-quotes` est déjà géré dans `AdminDashboard` : bascule vers l'onglet Devis filtré.

### Impact technique
- Aucune requête DB supplémentaire (`quotes` est déjà chargé via `useAdminRealtime`).
- Aucune migration.
- Fichiers modifiés : `AdminDashboard.vue` (prop), `RdvTab.vue` (computed + colonne).

## P2 — Tests Vitest pour RdvTab

### Objectif
Couvrir les fonctions pures de `RdvTab` par des tests unitaires.

### Extraction
Nouveau fichier `src/utils/rdvUtils.js` exportant les fonctions pures extraites de `RdvTab.vue` :
- `deriveFormat(a)` — déduit `online`/`inperson` depuis `raw.payload.scheduled_event.location.type`
- `ledPresence(a)` — retourne `present`/`absent`/`unknown`
- `getObjectRdv(a)` — extrait la première réponse Calendly ou `—`
- `fmtDate(iso)` — date fr ou `—`
- `fmtTime(iso)` — heure fr ou `""`
- `duration(start, end)` — durée en minutes ou `—`

`RdvTab.vue` importe ces fonctions depuis `@/utils/rdvUtils`.  
Pattern identique à `src/utils/formatters.js` (déjà existant dans le projet).

### Tests
Fichier `src/utils/rdvUtils.test.js`, style identique à `generateQuotePDF.test.js` :

| Fonction | Cas couverts |
|---|---|
| `deriveFormat` | `google_conference` → `online`, type inconnu → `inperson`, `raw` null → `inperson` |
| `ledPresence` | `present`, `absent`, `null` → `unknown` |
| `getObjectRdv` | qa valide, qa vide, `raw` null → `—` |
| `fmtDate` | ISO valide → `dd/mm/yyyy`, `null` → `—` |
| `fmtTime` | ISO valide → `hh:mm`, `null` → `""` |
| `duration` | 30 min, null start/end → `—` |
